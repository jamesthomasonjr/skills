# size-work

Write-spec blob used to letter the size-work family after specify-work.

Treat `weather-spec.md` as the already-sharpened spec. Do not treat
the skills repo, `docs/superpowers/`, or `eval-letters.md` as the
product.

| Path | What it is |
|---|---|
| `weather-spec.md` | Write-spec output (input to `size-work`) |
| `eval-letters.md` | RED/GREEN letters for the sizer (not input) |
